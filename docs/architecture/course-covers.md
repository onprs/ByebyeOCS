# 课程封面与共享图片缓存

本节说明正式服务和 Flutter 客户端的封面行为，适用于自托管用户环境。维护账号的现场回放只证明该次响应，不代表所有学校和课程都提供封面。

## 来源与展示

学习通课程列表的每个课程容器，按课程、班级和 CPI 的稳定入口关联名称与封面。重复链接不会推进图片索引；缺图课程不会借用下一门课程的图片。封面优先读取延迟加载地址，其次读取普通图片地址。可信平台给出的 HTTP 地址转换成 HTTPS，其他站点、嵌入凭据、非公开网络地址和不支持的协议均拒绝。

同步保存课程概要时一并保存封面来源，不等待完整章节读取。课程接口只返回 API 根目录相对的 `cover_url`，形如 `courses/<课程UUID>/cover?v=<来源摘要>`，不向客户端公开源站地址。首页主视觉、首页课程卡、课程列表和课程详情均使用同一套封面组件。

客户端通过现有 API 客户端加载图片，复用 Web Cookie 或原生 Bearer 与刷新流程；认证信息不放入图片 URL。无来源、正在加载、请求失败和图片解码失败都回落到原有图形占位，不增加弹窗或错误说明。主视觉的文字与图片分区，保证裁剪和文字可读性。

## 服务端缓存与访问

`GET /api/v1/courses/{id}/cover` 每次先检查课程归属，再读取共享缓存。匿名访问返回 401，其他用户的课程返回 404；命中缓存也不能绕过归属检查。图片按可信来源 URL 的 SHA-256 共享，同一图片的并发未命中合并回源，其他用户与服务重启可复用 PostgreSQL 缓存。

回源使用独立无 Cookie 客户端，不携带平台会话、业务令牌或个人页面 Referer。只请求已核对平台域名，保留现有 DNS/IP 和重定向检查及全局最小请求间隔；封面回源最多并发两个，单次共享读取有10秒上限。

原始响应最多2MiB，尺寸最多4096像素单边及400万像素。支持 JPEG、PNG、GIF 和 WebP，GIF只取首帧；解码后缩至最长边768像素，统一转为静态JPEG并去除原始元数据，单张最多256KiB。透明区域用白底合成。正常缓存24小时，失败缓存5分钟；来源变化会改变封面URL版本。

主库迁移26增加来源字段与共享图片表。缓存最多1024条，按最近写入保留，内容总量最多256MiB（不含数据库索引和行开销）；过期条目进入现有每批500行的维护清理。原始大图不落盘。返回支持 ETag 与条件请求，浏览器缓存为私有且按 Cookie、Authorization 区分。

## 客户端缓存与验收

客户端按当前身份代次隔离封面字节缓存，合并相同地址的并发请求，最多64条及8MiB，跨页面复用；退出、身份切换和服务切换后旧响应不能写回新缓存。图片解码宽度跟随展示尺寸并限制在768像素以内。

回归覆盖课程容器关联、重复入口和缺图、HTTPS规范化、无会话回源、尺寸及体积限制、共享缓存的归属检查、跨用户及重启命中、失败到期重试、来源失效、并发合并和条目上限。Flutter覆盖相对地址与认证、显示和兜底、缓存淘汰与会话隔离。实际课程列表的36张封面关联及一张图片的处理已通过维护环境私有响应回放，原始响应和图片不进入仓库。
