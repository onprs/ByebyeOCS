# 课程封面代理与共享图片缓存架构

> **适用范围**：正式 Go 主服务（`server/internal/learning/course_covers.go`）与 Flutter 用户端（`apps/client_flutter/lib/features/courses/course_cover.dart`）的封面安全获取、重编码压缩与双层缓存设计。

## 1. 源地址提取与防泄露边界

1. **同容器精确配对**：解析学习通课程列表 HTML 时，在每个独立课程容器内同时提取课程标识（`courseId`/`clazzId`/`cpi`）、课程标题与封面图地址（优先读取延迟加载属性，回退读取标准 `src`）。重复入口自动去重，无图课程留空，杜绝跨容器错位借图。
2. **源站 URL 净化与白名单**：仅接受已核实平台图片域名的地址，自动将可信域名的 HTTP 链接升级为 HTTPS；凡包含内嵌用户名密码、指向私有/回环 IP 或非标准协议的地址一律丢弃。
3. **相对代理地址输出**：课程概要保存时即记录封面源地址，无需等待章节快照完成。API 仅向客户端返回相对路径 `courses/<课程UUID>/cover?v=<源地址短摘要>`，隐藏上游真实 CDN URL，防止客户端直接向外部图床暴露本地 Referer 或网络指纹。

## 2. 服务端归属鉴权、无会话回源与重编码（迁移 26）

`GET /api/v1/courses/{id}/cover` 遵循“先验归属、再查共享缓存、最后隔离回源”的严格流水线：

- **强制归属校验**：未认证请求返回 `401`，访问非本人名下课程返回 `404`；即使目标图片已存在于跨用户共享缓存中，也绝不跳过课程归属校验。
- **独立无 Cookie 客户端回源**：缓存未命中时使用专用的无状态 HTTP 客户端回源，**不携带任何用户的学习通 Cookie、平台会话或业务令牌**，使用标准浏览器标识并通过 `singleflight` 合并相同源 URL SHA-256 的并发拉取；全局限制封面回源并发不超过 `2` 个，单次读取超时 `10s`，并复用平台域名/DNS 安全检查。
- **安全解码与静态 JPEG 归一化**：
  - 限制原始响应体不超过 `2 MiB`、单边不超过 `4096px`、总像素不超过 `400 万`。
  - 支持解码 JPEG、PNG、GIF（仅取首帧）与 WebP；解码后将透明通道合成白底，等比缩放至最长边不超过 `768px`，剥离全部 EXIF/原始元数据后统一重编码为体积不超过 `256 KiB` 的静态 JPEG。
- **PostgreSQL 共享缓存容量控制**：重编码后的字节流存入 `learning_course_covers` 表（原始大图绝不落盘），成功条目缓存 `7 天`，回源失败记录负缓存 `5 分钟` 防雪崩；全表上限 `1,024` 条且总字节预算不超过 `256 MiB`，超出时按最近写入淘汰旧条目。接口支持 `ETag` 条件请求，响应头设为 `Cache-Control: private, max-age=86400` 与 `Vary: Cookie, Authorization`。

## 3. Flutter 客户端代次隔离缓存与静默降级

- **复用鉴权通道加载**：客户端封面组件统一通过内置 `ApiClient` 请求封面字节，自动携带 Web 同源 Cookie 或原生 Bearer 令牌（图片 URL 查询参数中绝不拼接访问令牌）。
- **会话代次内存缓存**：客户端按当前登录会话代次维护最多 `64` 张、总量不超过 `8 MiB` 的内存图片缓存并合并同址并发请求，按展示尺寸约束解码宽度（上限 `768px`）；退出登录、切换账号或更换服务地址时立即递增代次清空旧缓存，阻止在途旧响应写回。
- **静默视觉回退**：课程本身无封面、网络加载中、回源失败或解码异常时，首页主视觉、首页课程卡、课程列表与详情页均平滑展示内置几何图形占位封面，不弹出错误提示打断用户浏览。
