# 安全防线与验证体系架构

> **适用范围**：开发维护与安全审计基准，汇总全栈纵深防御机制、脱敏边界、多层自动化测试矩阵及合规准入要求。

## 1. 全栈纵深安全防线

### 1.1 网络、跨站与请求解析防线

- **回环绑定与双域隔离**：主服务与题库服务仅监听回环地址；生产配置强制 `user_origin` 与 `admin_origin` 为两个不同的 HTTPS 域名，分别使用独立的 `HttpOnly`、`Secure` 会话 Cookie 名称，彻底隔绝跨端 Cookie 共享。
- **CSRF 与 Origin 精确门禁**：Web 用户端、管理员控制台与题库 `/panel/` 的所有状态修改请求均强制验证精确 `Origin`（拦截 `Sec-Fetch-Site: cross-site`）与会话绑定的 CSRF 令牌。
- **出站 SSRF 防御**：学习通适配器、封面无会话回源客户端与题库上游大模型客户端均校验 HTTPS 协议、域名白名单或显式 `allow_loopback_upstreams: false`（生产禁止向内网/回环 IP 发起模型请求），并对响应体大小、图片尺寸与总像素实施硬性截断。
- **请求体与头部限制**：HTTP 服务器限制最大请求头 `16 KiB` 并设置严格的 `ReadHeaderTimeout`，YAML 配置解码限制 `64 KiB` 且拒绝未知字段与多文档，私密文件读取前通过 `stat` 拦截 FIFO 命名管道与设备阻塞。

### 1.2 凭据零回显与密钥环防线

- **敏感材料隔离**：管理员密码采用 Argon2id 哈希，原生刷新令牌仅存 SHA-256 摘要，上游大模型密钥与 ZPay 商户密钥仅存于 `0600` 受保护文件中；任何 REST/SSE 响应、审计记录与结构化 JSON 日志均不输出明文密码、平台 Cookie、会话令牌或 API 密钥。
- **双密钥职责分离**：长期 `identity.key` 负责不可逆外部主体 HMAC 索引与用户缓存域派生；版本化 `application-vN.key` 负责 AES-256-GCM 密文封装，支持最多 8 版本解密环在线平滑轮换。
- **特权防锁死与步进验证**：内置拦截停用或降级最后一个有效 `owner`；调账、退款、改价、管权与闭户申请均受近期身份步进验证（Step-up Auth）保护。

## 2. 多层自动化验证体系

仓库构建了无需外部私有网络即可在 CI 与本地完整重放的五层验证防线：

1. **静态分析与契约一致性校验**：
   - Go 双模块 `gofmt` 与 `go vet ./...`；React 管理端 `tsc -b`；Flutter `flutter analyze`；
   - 设计令牌 `generate-design-tokens.py --check`（含 4.5:1 对比度校验）；
   - HTTP 处理器集成测试直接加载 `api/openapi.yaml` 校验请求与响应结构。
2. **并发竞态与账本不变量测试（`-race`）**：
   - 覆盖并发会话刷新重放熔断、并发预占/捕获/释放下的非负余额与借贷零和、重复支付通知幂等及乐观锁冲突。
3. **隔离 PostgreSQL 16+ 真实数据库集成测试（`-tags=integration`）**：
   - 测试套件自动在隔离 PostgreSQL 实例中创建并销毁随机 `byebyeocs_it_*` 临时数据库，端到端验证 34 个主库迁移、8 个题库迁移、行锁竞争、崩溃租约接管、防重放交卷、在途题库查询回收与 `reapply_privacy_closures` 恢复重放。
4. **三端组件与真实浏览器测试**：
   - 管理端 Vitest 单元测试与 Playwright 端到端测试；Flutter 组件/路由/缓存代次隔离测试；独立题库面板 Chrome 真实浏览器读写与权限回归。
5. **部署、备份与跨平台开发脚本隔离测试**：
   - `scripts/test-configs.sh` 用真实二进制校验公开配置样例；`scripts/test-deploy.sh` 在沙盒目录结合伪 SSH 与真实临时 PostgreSQL 验证安装、升级、回滚、`pg_dump` + `age` 加密备份与 `restore-drill.sh` 恢复；`scripts/dev/ci-smoke.mjs` 在 Ubuntu 与 Windows 双平台验证全栈拉起与 Go 热编译重启。

## 3. 运行监控与外部合规边界

- **低基数可观测性**：管理端健康、维护与题库回收接口仅暴露聚合计数、资源水位与脱敏状态码，指标标签不包含用户姓名、学号或完整题目文本。
- **受控夹具与真实环境边界**：上述自动化测试证明代码逻辑、并发锁与协议解析在受控样本下的正确性；在生产环境面向真实用户开启服务前，部署者仍须独立核实目标学校课程授权、ZPay 商户经营准入、上游大模型数据处理条款、异机备份恢复演练及移动客户端合规分发资质。
