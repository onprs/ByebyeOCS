# 决策 0002：默认采用石墨配色并保留三套外观切换

- **状态**：已采纳并落地

## 背景

第一阶段视觉探索提供了石墨（`graphite`）、青禾（`grove`）与靛蓝（`indigo`）三套配色方案。经审阅确认整体信息结构合适，需要将其中一套定为首次访问默认方案，同时保留用户与管理员按个人阅读习惯切换配色的自由度。

## 决策

1. 全平台（用户端、管理员控制台、独立题库维护面板）统一将 **`graphite`（石墨）** 设为默认配色方案；当未设置偏好或读取到无效配置值时自动回退至石墨。
2. 完整保留 **`grove`（青禾）** 与 **`indigo`（靛蓝）** 两套可选配色，并独立支持**跟随系统（`system`）、浅色（`light`）、深色（`dark`）**主题模式。
3. 三套外观共享完全一致的组件几何尺寸、圆角与字级密度，仅切换经 WCAG AA（`>= 4.5:1`）对比度校验的语义色板；切换外观纯粹属于视图层偏好，不改变任何业务数据、权限或任务状态。
4. 普通用户、主平台管理员与题库面板维护员各自独立持久化外观偏好，互不串写。

## 当前落点与影响

- 单一令牌源定义在 `design/tokens.json`，由 `scripts/generate-design-tokens.py` 自动输出管理端 CSS、题库面板 CSS 与 Flutter `AppPalette` 代码。
- 用户端与管理端通过 `user_preferences` / `admin_preferences` 表及乐观锁 API 跨设备同步外观设置，设置界面统一采用直观的配色卡片与主题预览组件呈现。
