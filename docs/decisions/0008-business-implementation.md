# 0008：完整业务工程与本地交付边界

状态：依据用户“继续，先一次性把项目完成”及后续继续指令实施。外部授权、价格、商户、真实模型与签名仍是对应能力的启用条件。

## 实现

- 正式主服务为 `server/` Go模块，独立题库为 `services/tiku/`；PostgreSQL为唯一正式主数据库，题库独立数据库与角色。
- 管理端为 `apps/admin/` React工程，用户端为 `apps/client_flutter/` 同一Flutter Web/Android/iOS工程。React手机原型继续保留在 `prototypes/`。
- 已实现认证/RBAC、课程/安排/租约调度、平台确认与媒体证据分离、整数分账本、ZPay适配、题库模型/精确缓存/token、事件、运维保护、导出和删除复核。确切接口以OpenAPI与代码为准。
- 身份索引与缓存作用域使用独立长期密钥；加密主密钥版本化，旧keyring支持读取及分批重封装。正常轮换不重建用户、钱包或稳定任务键。
- 任务确认事实独立于收费保存，停收费/未定价/零价也保留计量。任务冻结启动价格，题库冻结每模型价格与收费决策；后台发布新价不追补旧请求。
- 资金以整数分和不可变双分录记录。人民币每分10000微元，比例与舍入规则显式配置；不产生默认公开价格。
- 隐私完成需资金和运行阻断清零；清理非必要内容与可用秘密，保留opaque归属、必要财务/去重/审计及防复活标记。

## 交付与验证

Linux原生程序与两套静态应用可组成校验发布目录；提供安装/升级/回滚/卸载、systemd、HTTPS代理样例、age一致性备份和隔离恢复工具。所有生产业务副作用默认关闭，初始管理员用私有文件显式创建。

本地使用隔离PostgreSQL和测试二进制内的合成验证器/课程/模型计量，验证实际HTTP、Cookie/CSRF、SSE、调度和账本组合；正式二进制不包含这些夹具。Flutter已有Web release和Android debug APK，iOS只建立源码工程。最新证据与限制见 [当前实现](../development/local-implementation.md)。

本次业务工程交付时工作区尚无Git仓库，没有提交、推送、上线或创建GitHub Release。后续已按用户指令初始化本地Git，实际状态见开发验收记录。没有真实平台/商户/上游调用和有效签名时，不把合成数据或调试包描述成完成外部能力。
