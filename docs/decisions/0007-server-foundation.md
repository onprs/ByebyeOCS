## 决定

正式服务使用独立的 `server/` Go 模块，与 React 原型、保留的研究目录并列。研究目录包含实验入口和多份源码快照，不纳入正式服务的包扫描和测试。模块声明 Go 1.26；数据库连接要求 PostgreSQL 16 起，当前现场验证版本为 16.15。

本轮交付启动配置、双端独立回环监听、能力发现、存活与就绪检查、显式迁移、基础身份/偏好/审计表及验证。已实现接口固定于 `api/openapi.yaml`；其余业务契约尚未冻结。能力接口中的认证、业务与收费均为关闭状态。

迁移与服务启动使用独立命令。内置 SQL 随二进制发布，事务级咨询锁串行迁移，SHA-256 核对应用记录；失败整批回滚。服务和只读诊断发现未迁移或不兼容记录时拒绝就绪。

配置覆盖顺序为命令行、环境变量、YAML、默认值。数据库 URL 仅通过环境变量或私有文件提供；远程连接要求完整 TLS 验证，本地回环可显式关闭 TLS。当前未实现应用认证，监听仅接受回环 IP。
