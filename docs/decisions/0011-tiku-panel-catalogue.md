# 决策 0011：公开模型目录与价格归题库面板

状态：用户已确认。公开模型条目、token 价格与缓存策略由题库服务的维护面板维护，数据保存在题库独立 PostgreSQL；本决定覆盖[决策 0006](0006-tiku-fork-token-billing.md)中“主平台管理员创建公开条目、主库保存价格”的归属安排，其余查询、计费与账本边界不变。

## 背景

独立题库面板已经承担模型启停、模型测试、精确缓存失效、查询与用量查看。公开模型条目和价格仍由主管理端维护，配置分散在两个入口，且题库面板读取的模型能力与主平台公开条目之间需要人工保持同步。用户明确要求题库与模型相关配置统一放到题库专有面板，并在管理员面板提供跳转按钮。

## 决策

### 1. 题库是公开目录的唯一来源

- 题库数据库新增 `tiku.offerings`：公开名称、说明、能力、`provider_ref`、价格、缓存策略、默认与可见状态。
- 价格版本保存在 `tiku.offering_price_versions`，只追加；同一版本不能改写费率。
- 上游模型密钥、真实上游模型名和地址仍只存在于题库配置与私密文件；面板可以编辑这些条目，但密钥只写入 `secrets/` 下 0600 文件，不进入主库、数据库或浏览器响应。
- 主平台的 `public.question_offerings` 改为同步镜像，只用于查询外键、历史展示与用量汇总；主库不再拥有定价权。
- 已发布的公开条目不提供删除，只能下架；下架不删除历史查询和冻结价格快照。

### 2. 题库维护面板是唯一写入入口

- `/panel/` 的“模型与价格”页面新增、编辑、删除上游模型及密钥，保存后热加载；同一页面发布、编辑与测试公开条目，维护默认项、可见性、价格版本和缓存策略。
- 上游模型元数据原子写回题库配置文件，写前使用正式配置加载器校验；删除仍被公开条目引用的模型会被拒绝。
- 主管理端保留只读目录、查询、用量与答案报告复核，不提供公开条目的新增、编辑、启停或测试接口。
- 主管理端与系统设置提供“进入题库面板”按钮，默认同域 `/panel/`，可用 `VITE_TIKU_PANEL_URL` 覆盖。
- 面板使用独立维护账号；主管理端管理员权限不自动获得题库面板写入权。

### 3. 主平台按目录报价并冻结事实

- 主平台通过题库内部接口读取公开目录，校验编号、价格版本、缓存策略与健康状态；目录格式无效时拒绝使用，不猜测价格。
- 每次新查询把公开条目、价格版本、缓存策略与用户范围冻结到查询行；后续目录改价不改变已发生查询的结算依据。
- 钱包、预占、结算、释放与账本仍由主平台拥有；题库只返回 token 事实，不修改余额。
- 主平台发送 `provider_ref` 调用 `/api/v2/answers`；公开条目 ID 与上游模型引用不混用。
- 缓存期限由题库面板按 `cache.max_ttl_days` 校验；主平台在调用模型前继续拒绝超限或未启用的缓存策略。

### 4. 迁移与兼容

- 主平台新增连续迁移：公开条目表改为镜像，删除主库价格版本表和主库模型测试表。
- 题库新增公开条目与价格版本迁移；面板与内部目录接口新增后，主平台不再注册公开条目写接口。
- 旧主库价格版本或模型测试记录不迁移到题库；当前没有真实业务数据，迁移不自动生成模型、价格或测试记录。若升级环境已有主库公开条目，需要在题库面板重新发布后才能继续被用户选择；不提供跨库自动复制脚本。

## 验收范围

- 题库面板可发布、编辑、下架公开条目并发布不可变价格版本；只读账号不能写入。
- 主平台用户模型列表、查询报价、安排策略校验与管理员用量都读取题库目录；主平台写接口返回方法不允许。
- 查询价格快照在目录改价后保持不变；缓存策略与共享缓存限制继续生效。
- 真实上游模型、真实课程与生产容量仍需对应授权和现场配置，不能由隔离夹具替代。
