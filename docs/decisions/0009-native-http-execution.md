# ADR0009：正式任务使用原生HTTP执行

状态：已确认。用户明确正式任务通过直接请求完成，不使用浏览器或媒体播放器。

## 决策

- 正式执行入口装配`chaoxing.HTTPExecutor`，移除浏览器执行代码、浏览器路径配置和降低进程保护的浏览器drop-in。
- 当前支持能取得普通请求上下文的视频任务点：绑定课程/班级/章节/任务点，读取新鲜卡片和元数据，核对保存位置、时长、普通请求间隔、请求入口和签名字段。
- 按真实经过时间推进执行位置，保持平台下发节奏；不提供位置覆盖、倍速、重复参数、时长覆盖、修改计时或跳过交互的开关。
- 抓拍、验证码、视频内交互、身份失效、403、429及未知协议停止相关操作；不猜测字段、补写成功或无限重试。
- `Completed`只表达执行阶段结束。调度器执行前预检、结束后独立核验，按平台确认决定有效任务点及账本处理。
- 原生请求不产生真实媒体播放证据。执行记录、平台确认和播放记录继续独立建模，无解码或播放器记录时`Media.Available=false`。
- 单任务租约与fencing、账号并发限额、预占/结算/释放保持现有契约。恢复时先核验，再按平台保存位置重新准备普通请求。

## 配置与资源

`learning.execution_enabled`仍默认关闭，启用要求平台接入授权和独立`execution_evidence_reference`。不再接受`browser_executable`。未知配置继续严格拒绝，运维应移除旧字段后检查配置。

全局执行并发按配置生效，取消过去为浏览器强制压为1的装配逻辑。题库新增`database_max_connections`，默认4，低内存起点为2；连接池不再随宿主CPU数量隐式扩大。题库的连接和密钥相对路径按配置文件目录解析。

2C1G列入低并发验证规格。使用预构建应用、有限连接和并发、Go内存软目标及PostgreSQL预算；结果和适用范围见[容量记录](../architecture/capacity.md)。构建环境与运行环境分开，Chrome只属于前端维护测试工具。

## 验收边界

本地TLS协议夹具验证普通签名向量、平台上下文、真实节奏语义、暂停取消、并发、交互停止、错误分类与无播放证据。Go/PostgreSQL集成检查继续覆盖确认和账本边界。

本地资源检查不证明真实学校兼容、真实平台授权、真实完成或长期容量。真实平台操作、付款和自动收费仍需配置与对应证据，不通过本次改动自动开启。
