## 2. 生产外部能力启用准入标准

仓库内的自动化单元、竞态、隔离 PostgreSQL 集成测试与浏览器端到端测试均基于受控本地夹具运行。任何公开自托管实例在生产环境开启对应开关前，必须逐项满足以下准入条件：

### 2.1 学习通连接与原生执行准入

- 已确认目标学校与课程的合法接入依据，并在主配置填入稳定的 `subject_namespace` 与探针参数（`json` 或 `profile` 模式）。
- 已使用授权测试账号在目标课程上完成只读同步、章节目录层级、任务点识别与小批量原生执行实测，填入 `execution_evidence_reference`。
- 明确知悉未支持题型（如连线、排序、口语等复杂交互题）及平台强制本人核验（验证码、人脸识别）会自动暂停转人工处理，不向终端用户作超出实际覆盖范围的承诺。

### 2.2 独立题库与模型计费准入

- 已在独立 PostgreSQL 实例初始化题库 8 个连续迁移，配置至少 32 字符的内部服务令牌与 `/panel/` 维护员强密码哈希。
- 已在 `/panel/` 完成上游模型服务商授权接入、无 token 连通检查与显式确认用量的功能测试，核实上游协议能返回完整的 `input + output = total` token 统计。
- 已为每个对外开放的模型发布公开条目与微元价格版本；确认共享缓存开关（默认按用户隔离）符合部署方隐私披露政策。

### 2.3 资金收款与容灾保护准入

- 已配置定时异机 `age` 加密备份（`deploy/backup.sh`），完成至少一次非 root 隔离恢复演练（`deploy/restore-drill.sh`），并验证离线私钥可独立解密还原两库与完整密钥环。
- 已在 ZPay（`zpayz.cn`）完成真实商户开户、通道审核与密钥配置，在真实 HTTPS 公网回调链路上完成小额下单、异步验签入账、重复通知幂等、主动查单及原路退款实测。

### 2.4 移动客户端分发准入

- **Web 端**：优先作为全平台（桌面、Android、iOS）零安装门槛的标准入口。
- **Android 原生端**：需准备独立的发布签名密钥库（妥善离线保管并保持升级签名连续性），构建签名 release APK 并托管至自有 HTTPS 下载站，随附版本清单与 SHA-256 校验值。
- **iOS 原生端**：在未取得有效 Apple 开发者分发资质与满足对应地区系统要求前，继续通过 Safari / Web 端提供服务，不提供未签名或违规企业证书直装包。
