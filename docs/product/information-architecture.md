# 信息架构与原型路由

设计评审原型默认监听 `127.0.0.1:5186`。正式React管理端与Flutter客户端独立构建，通过Go服务与自己的HTTPS入口运行，安装见 [部署指南](../../deploy/README.md)。

## 评审入口

`/review` 展示三套真实页面缩略预览。可切换管理端、用户端和手机布局，进入后使用顶部评审工具切换方向、主题和演示场景。

查询参数：

| 参数 | 值 | 用途 |
| --- | --- | --- |
| `design` | `graphite` / `grove` / `indigo` | 三种外观，默认石墨 |
| `theme` | `light` / `dark` | 浅色或深色 |
| `embed` | `1` | 隐藏评审工具栏，方便截图与嵌入 |

## 管理员控制台

| 路由 | 页面结构 | 补充参数 |
| --- | --- | --- |
| `/admin/dashboard` | 运行摘要、任务趋势、资源、任务与财务事件 | 无 |
| `/admin/accounts` | 账号概览、搜索筛选、数据表、批量条、详情抽屉 | `search`、`state` |
| `/admin/tasks` | 并发摘要、状态标签、任务表、执行详情 | `search`、`owner`、`status=attention` |
| `/admin/questions` | 公开模型目录、缓存策略、token 用量、查询与测试 | 无 |
| `/admin/finance` | 财务指标、趋势、渠道、订单、流水和审计 | 无 |
| `/admin/settings` | 12 类设置、当前配置、测试结果与保存操作 | `section` |

全局搜索可以从用户编号、姓名、课程或任务跳转到已筛选页面。任务和用户支持相互定位。

## 用户 Web

| 路由 | 主要内容 |
| --- | --- |
| `/client/login` | 账号密码、候选扫码、授权、验证码与过期 |
| `/client/home` | 当前身份、课程和任务摘要、安排、提醒及余额 |
| `/client/courses` | 课程搜索、待完成/已确认筛选、同步 |
| `/client/courses/:id` | 课程摘要、任务点进度、章节树与普通学习资料 |
| `/client/plans` | 安排列表、可编辑内容、实时任务、异常与历史；测验的模型和作答方式 |
| `/client/wallet` | 余额、充值、订单与明细、题库 token 用量、计费与异常说明 |
| `/client/settings` | 会话、通知、主题、安全、数据申请与退出 |

安排页支持 `plan` 定位安排、`course` 预选课程并打开创建面板。课程页的 `filter=pending` 可直接定位待完成课程。测验安排还可选择题库面板发布的模型与“缓存优先/每次调用模型”；答案详情展示模型、缓存命中与 token 分解。

题库维护面板“模型与价格”负责上游模型与密钥、公开模型条目、默认项、价格版本、缓存作用域和模型测试；主管理端“题库查询与用量”只读目录、核对查询/用量与答案报告并跳转面板。上游密钥留在独立 fork，不通过浏览器进入主平台。

正式用户端已确定 Flutter Web + Flutter Android/iOS；当前这些可操作路由仍属于 React 视觉原型，后续按同一信息架构实现 Flutter。主服务按用量计费、题库独立计费，具体价格未公布。

## 手机视觉原型

使用 `/mobile/login`、`/mobile/home`、`/mobile/courses`、`/mobile/courses/:id`、`/mobile/plans`、`/mobile/wallet`、`/mobile/settings`。

宽屏访问展示手机容器和评审说明；窄屏访问使用真实视口宽度，底部导航独立布局。与 Web 共享原型组件和业务状态，不代表已有 Flutter 工程或原生 App。

## 权限边界

本轮路由和角色为演示。正式系统需要独立管理入口、管理员认证与权限；用户 API 按内部用户验证归属，不能通过知道另一个用户的资源编号访问其数据。原型中的跨端状态共享用于评审，不可作为正式权限设计。
