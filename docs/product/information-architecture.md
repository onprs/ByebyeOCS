# 三端信息架构

> **适用范围**：产品与前端信息结构规范，对应 `apps/client_flutter/`、`apps/admin/` 与 `services/tiku/internal/platform/panel/` 的正式路由与视图组织。

系统按职责与安全边界划分为三个相互独立的 Web/客户端入口：**用户客户端**、**管理员控制台**与**独立题库维护面板**。三端共享设计令牌，会话、权限与导航完全隔离。

## 1. 用户客户端（Flutter Web / Android / iOS）

桌面端采用顶部居中滑块导航加右上角个人头像入口；移动端采用底部四栏主导航（首页、课程、任务安排、钱包）加右上角个人头像入口。主导航壳层通过 `StatefulShellRoute.indexedStack` 保留各栏目的滚动位置与筛选状态。

| 路由路径 | 页面名称 | 核心内容与操作 |
| --- | --- | --- |
| `/startup` | 启动恢复页 | 校验本机会话与服务能力，完成后恢复原目标路径或跳转登录 |
| `/login` | 学习通登录页 | 输入学习通账号与密码，移动端提供底部“连接服务”入口 |
| `/connect` | 连接服务页 | 供 Android/iOS 原生端填写并校验自托管 HTTPS 服务地址 |
| `/home` | 首页 | 主视觉课程封面、学习统计条、课程内联同步状态、可处理异常提醒、近期安排与最近平台确认记录、钱包快捷卡 |
| `/courses` | 课程列表页 | 课程搜索、进行中与已结束标识、封面卡片、任务点完成进度及一键发起安排 |
| `/courses/:id` | 课程详情页 | 课程头部进度、按章分组与多级折叠树展示小节（含关闭小节状态）、区分有效任务点与普通学习资料 |
| `/plans` | 任务安排页 | 安排切换与新建/编辑（桌面右侧栏、移动底部面板）、当前版本总进度条、按分类游标分页的任务列表、单任务进度条与任务详情抽屉 |
| `/wallet` | 钱包页 | 可用余额与冻结预占、在线充值下单、充值订单列表（区分已付待入账与已到账）、账务流水明细与题库 token 用量记录 |
| `/settings` | 个人设置页 | 账号主体与学校信息、配色卡片与主题预览、题库查询入口、通知开关、活跃会话管理、加密数据导出与账号删除申请 |
| `/settings/questions` | 独立题库查询页 | 选择已发布模型与复用模式，手动查询题目答案、查看 token 明细并在页内展开提交答案问题报告 |
| `/deletion-receipt` | 删除回执页 | 账号删除申请提交并吊销会话后的状态说明与受理回执展示 |

## 2. 管理员控制台（React）

管理员控制台部署在独立的管理员 HTTPS 域名下，采用左侧固定导航栏（窄屏收纳为抽屉）加右侧主工作区布局。路由与操作按五种角色（`owner`、`operator`、`support`、`finance`、`observer`）精确门控，无权限的导航项自动隐藏，直接访问受限路由将被拦截。

| 路由路径 | 导航名称 | 准入权限 | 核心内容与操作 |
| --- | --- | --- | --- |
| `/login` | 管理员登录 | 公开（未登录） | 管理员用户名、密码与 6 位 TOTP 动态码校验 |
| `/dashboard` | 运行总览 | `learning.read` | 系统健康与备份/磁盘状态带、核心业务指标（区分 `closed` 与 `actionable_attention`）、运行资源水位、活跃任务、今日财务与实时事件流 |
| `/users` | 用户与账号 | `learning.read` | 用户搜索与会话状态筛选、当前页多选批量操作（暂停任务、调整并发、限制账号，需 `learning.accounts.operate`）、脱敏主体与钱包详情抽屉 |
| `/tasks` | 任务监控 | `learning.read` | 全局与单账号并发摘要、状态分类筛选、观察进度与平台确认独立列、任务时间线详情、批量控制（需 `learning.tasks.operate`），以及底部待处理题库答案报告复核区 |
| `/finance` | 财务与订单 | `billing.read` | 充值订单管理、不可变复式账本流水、ZPay 主动查单对账（`reconciliation.manage`）、异常退款审批（`wallet.refund`）与步进验证人工调账（`wallet.adjust`） |
| `/administrators` | 管理员管理 | `admin.users.manage` | 创建管理员、分配角色、启停账号、重置凭据，强制保护最后一个有效 `owner` |
| `/privacy-requests` | 隐私请求 | `privacy.review` | 查看与复核用户数据导出记录及账号闭户删除申请 |
| `/settings` | 系统设置 | `admin.self`（子项按权限过滤） | 分为**外观偏好**、**计费与价格**（`billing.read`/`billing.manage`）、**运行安全**（`operations.read`/所有者热调并发与请求节奏）、**维护信息**（`operations.read`）四个分组 |
| 同域 `/panel/` | 题库维护面板 | 独立题库会话 | 从左侧栏跳转独立题库维护面板，主管理端不内嵌模型密钥或题库定价表单 |

## 3. 独立题库维护面板（`/panel/`）

题库维护面板由 `ocs-tiku-fork` 二进制直接提供静态资源与 `/panel/api/*` 接口，经管理员域名反向代理挂载在 `/panel/` 路径下，使用独立的维护员（读写）与观察员（只读）账号体系：

- **运行总览**：展示最近 14 天查询总量与精确缓存命中趋势图、累计按模型调用分布图、全局 token 汇总及最近查询动态。
- **模型与价格**：集中管理大模型提供商（支持连通性探测与上游模型目录检索）、上游模型实例（保存后原子写回私密配置并热加载）以及一对一绑定的公开模型条目（自动拉取外部参考价换算微元费率、追加不可变价格版本、配置默认缓存期限与可见性）。
- **查询记录**：分页检索请求详情、题目摘要、模型槽位调用（作答槽位与视觉转述槽位）及 token 消耗状态。
- **精确缓存**：按模型与状态检索有效缓存条目，支持填写原因立即失效错误缓存。
- **操作记录**：审计面板内所有配置变更、条目发布、功能测试与缓存失效记录。
- **面板设置**：切换面板自身配色与浅深主题，查看运行限制参数，在线调整并立即刷新外部模型参考价目录与汇率缓存 TTL。
