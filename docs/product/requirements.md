# 产品需求规范

> **适用范围**：产品功能范围与边界基准，同时指导公开部署配置与工程实现。

## 1. 目标角色与核心价值

ByebyeOCS 面向需要集中查看学习通多门课程进度、按规则自动执行支持类型的学习任务、并对账户用量与资金流水保有清晰可查账目的自托管团队与终端用户。系统围绕三类角色构建：

- **学习用户**：通过本人学习通身份进入 Web、Android 或 iOS 客户端，管理课程同步、多课程学习安排、自动做题偏好、钱包充值及个人隐私请求。
- **平台管理员**：通过独立管理员控制台监控系统水位、用户会话、任务队列、财务订单与隐私工单，按角色权限（`owner`、`operator`、`support`、`finance`、`observer`）执行运维与对账动作。
- **题库维护员**：通过独立题库维护面板（`/panel/`）管理上游大模型服务商、模型配置与 API 密钥，发布公开模型条目、微元价格版本与精确缓存策略，排查查询记录与失效错误缓存。

## 2. 用户端功能需求

### 2.1 身份进入与服务连接

- 用户使用学习通账号与密码登录，服务端经受信任探针核验不可变外部主体后自动绑定唯一内部用户与钱包，无独立平台注册流程。
- 学校名称由服务端探针自动获取并展示；登录失败或平台要求额外验证时明确提示原因。
- 原生移动端支持在“连接服务”页配置自托管用户端 HTTPS 地址；切换地址自动清理本机旧会话与缓存。

### 2.2 课程目录与三级可用性

- 进入首页或课程页自动启动或接续两阶段课程同步：先展示完整课程列表与封面，再逐门拉取多级章节树、任务点与普通学习资料。
- 保留课程原有的章分组、父子层级与编号；普通无任务点编号的附件仅作资料呈现，不计入待完成分母。
- 自动识别课程已结束、章节未开放/已关闭、测验未开放/已截止三级平台状态，将其排除出待处理提醒与完成率分母，并提供手动“重新检查可用性”入口。

### 2.3 学习安排与任务控制

- 支持创建多份学习安排，按课程名或教师模糊筛选多选课程，覆盖所选课程的全部可用章节，配置任务类型（视频、音频、文档、测验）与优先级。
- 启用测验自动作答时，从已发布的公开模型列表中选择目标模型（标注图片题支持能力），并选择“优先复用答案”或“每次调用模型”。
- 展示服务端汇总的当前安排总进度条及单任务实时进度条；支持按分类（当前、需要处理、已关闭、已完成等）分页浏览任务，支持暂停、继续、取消、重新调度及归档删除安排。

### 2.4 独立题库查询、钱包与隐私

- 个人设置内提供独立题库查询页，支持手动输入题目查询已发布模型答案并提交答案问题报告。
- 钱包页清晰区分“支付成功待入账”与“余额已到账”，独立展示充值订单、账务流水与题库 token 消耗明细；正常到账余额原则上不提供自助提现退回，异常资金走人工对账与退款流程。
- 个人设置支持切换石墨（默认）、青禾、靛蓝配色与浅深主题，管理活跃设备会话、通知开关，发起加密数据导出与账号删除申请。

## 3. 管理端与题库面板功能需求

- **运行监控与任务处置**：汇总用户规模、活跃租约、队列积压、资源水位及可处理异常数；支持按条件筛选用户与任务，执行当前页多选批量暂停、限制账号或调整单账号并发上限。
- **答案问题复核**：在任务监控页集中展示待处理的用户答案报告，支持记录复核结论或联动独立题库使错误精确缓存失效。
- **财务核算与对账**：支持配置有效任务点微元单价、舍入规则与收费总开关；提供 ZPay 订单查询、主动对账、原路退款/服务退回审批及带步进验证的人工余额调整。
- **运行参数热调与权限治理**：`owner` 可在线调整全局并发、单账号并发、章节同步并发及上游请求间隔并持久化；支持多角色管理员生命周期管理与最后一个有效 `owner` 保护。
- **独立题库治理**：在 `/panel/` 独立完成提供商连通探测、模型目录搜索、配置热加载、参考价自动填入、一对一公开条目发布、价格版本追加与缓存管理。

## 4. 非功能指标与明确排除项

### 4.1 非功能要求

- **资源目标**：面向约 2C4G 内存、30GB 磁盘的 Linux 单机部署目标设计有界连接池、有界协程池、分层数据清理与三级磁盘水位熔断。
- **真实性红线**：执行观察进度、独立平台确认与真实媒体播放证据三者严格分立；严禁用本地倒计时冒充平台确认，严禁用模糊检索冒充精确缓存，未定价或 token 用量缺失时禁止自动扣费。
- **容灾目标**：提供一致性逻辑加密异机备份与 15 分钟恢复点新鲜度门控，灾难恢复后强制通过 `.recovery-required` 对账解锁。

### 4.2 明确排除范围

- 不在服务端运行无头浏览器、媒体播放器或音视频解码器执行生产学习任务。
- 不提供视频倍速篡改、时长伪造、跳过平台强制人脸/验证码校验等破坏平台校验边界的开关。
- 不在客户端本地后台执行学习任务，移动端切入后台不影响服务端调度，回到前台重新拉取服务端权威状态。
- MVP 阶段不引入多节点分布式调度锁、Redis 或外部消息中间件。
