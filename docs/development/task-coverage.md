# 任务覆盖与完成判定

本文记录开发维护环境中的代码检查、受控HTTP协议和隔离PostgreSQL证据。公开用法见README；真实学校课程兼容性仍需对应账号与目标课程验证。

## 完成的含义

自动做题的正常路径是：安排领取任务、重新核对平台状态、读取当前试卷、按冻结模型查询、确定性映射、重新读取并比对试卷、最终提交、独立读取任务点状态。没有人工确认步骤。

请求结束和答案被接收只结束执行阶段。只有独立平台读取返回明确通过，任务才成为`confirmed`并进入有效任务点计量。分数不足、等待批阅、未知响应和平台尚未确认均保留未完成事实；模型能生成答案不代表答案正确。未知最终提交不自动重放。

## 当前任务覆盖

| 平台任务 | 项目分类 | 自动执行路径 | 范围 |
| --- | --- | --- | --- |
| 普通视频 | video | 原生音视频请求，按实际经过时间和保存位置执行，再独立核验 | 可信元数据、正常节奏、无抓拍或内嵌交互 |
| 明确音频任务，或video卡片中明确标为音频文件 | audio | 同一原生执行器使用Audio协议，再独立核验 | 音频类型需由平台卡片明确给出，不盲目尝试其他类型 |
| 文档与演示文稿任务点 | document | 当前卡片jtoken对应的`/ananas/job/document`请求，再独立核验 | 仅有效任务点；普通附件不计入未完成 |
| 阅读任务点 | document | 当前卡片jtoken对应的`/ananas/job/readv2`请求，再独立核验 | 完成任务点请求，不据此生成阅读时长 |
| 章节测验 | quiz | 自动取题、模型查询、填写、最终提交、独立核验 | 支持的题型与表单见下表 |
| 未知或尚未实现的活动类型 | other | 保留稳定任务点及未完成事实 | 直播、签到、讨论、独立考试等没有通用自动执行承诺 |

服务能力端点返回当前执行器支持的任务分类，客户端根据该结果显示类型可用性；实际执行开关单独表示。`other`保留任务点，不因分类未知而遗漏，也不作为已完成处理。

## 测验题型与表单

单选、多选、判断、填空及简答通过原生提交回归。按当前页面真实选项值、空位字段名和原始题型码提交；填空既覆盖普通输入框，也覆盖已识别的富文本编辑器字段及同名重复空位。布尔`disabled`/`readonly`属性按存在性判断，防止已提交结果页被当成新试卷。

名词解释、论述和计算的纯文本作答能力按真实页面字段验证，保留原始题型码。存在唯一可写文字字段时，可选附件工具不阻止文字作答；必填上传、仅附件作答、录音、组合小题、排序、连线及未知表单结构没有通用支持。教师要求的作答形式、评分规则和平台完成状态继续由平台决定。

## 已修复的遗漏与错误

- 原来固定请求`num=0`，遗漏同章后续卡片。现在读取章节卡片目录，保存每个任务的卡片页码；发现、租约领取、取题、执行前检查和独立核验使用同一页码。主库迁移000018新增`learning_attachments.card_index`。
- 合法空卡片可以同步。超出章节或卡片上限时报告不完整读取，不静默截断目录。单章最多32张卡片，章节数量使用既有上限。
- 阅读和未知类型统一映射为可展示分类；有稳定jobid的任务点即使缺少objectId仍被保留，具体执行器再核对该协议必需的资源字段。
- 章节待完成计数只在对应DOM节点内读取，防止把下一章节的0错误当作当前章节完成。
- 章节同步复用稳定章节标识，选定章节安排按外部章节身份绑定；暂停期间发现的新任务在恢复时补齐绑定。
- 领取时重新核对安排范围，并选择可执行的测验策略；历史绑定不能替代当前安排条件。同账号任务按当前有效安排的最高优先级领取，实际执行携带选定策略的优先级。
- 最新完整快照中已消失的任务停止领取，在途任务通过既有停止握手终止；保留运行意图、原报价和预占。任务重现后只恢复由快照缺失造成的状态，用户暂停和取消保持不变；已有最终提交事实时只核验。
- 配置同步批量上限时，课程数超过上限会明确报告未完成同步，不把截断的目录记为完整成功。
- 重试沿用冻结报价及预占引用，防止改价或关闭收费时覆盖原预占、产生重复报价或资金滞留。
- 测验读取真实表单内题目；可见验证控件、禁用控件、富文本与重复填空字段均有回归。课程题干或标题中的“验证码、登录、权限”不会直接作为平台验证要求。
- 取题、图片读取、重新验卷和最终提交在同次执行中共享Cookie轮换。容器按平台实例与原始会话指纹隔离，不跨账号或任务共享；未开启执行作用域的独立调用仍各自隔离。当前仅保持单次执行内连续性，轮换Cookie不写回持久会话，跨执行兼容尚待真实平台核实。

## 证据与限制

新增组合测试使用正式原生平台适配器、正式学习调度器和真实隔离PostgreSQL。任务位于后续卡片，整卷五种基本题型的实际POST字段由本地TLS平台夹具检查。平台独立读取返回通过时任务自动成为confirmed；只接收提交但不返回通过时保持未完成，最终POST只发生一次。

音频测试核对Audio请求类型、保存位置与实际经过时间。文档与阅读测试核对任务令牌、章节归属、实际卡片和独立完成读取。调度回归覆盖选定章节重新同步、暂停恢复、当前范围、优先级、任务消失/重现、在途停止、提交后只核验、价格冻结和原预占延续。TLS夹具还要求携带取题下发的Cookie，验证取题到提交的连续性与账号容器隔离。

以上证明实现与已建模协议之间的行为。当前没有真实学校页面、作答机会、最终提交、模型正确率或真实任务点完成的现场证据；字体加密、特殊作答控件、批阅等待和学校差异不能从夹具通过推断为兼容。
