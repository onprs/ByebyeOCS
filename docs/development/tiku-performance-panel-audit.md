# 题库维护面板治理与参考价缓存机制

> **适用范围**：开发维护环境，说明独立题库维护面板（`services/tiku/internal/platform/panel/`）的提供商与模型热管理、外部参考价与汇率本地缓存、面板安全控制及统计查询设计。

## 1. 提供商集中管理与上游模型热加载

1. **提供商探测与模型目录发现**：维护员在 `/panel/` 的“模型与价格”页面添加模型服务商（支持 OpenAI Chat、Anthropic Messages、Google Gemini、Ollama 等协议）后，可一键触发连通性探测并拉取上游 `/models` 目录，按关键字搜索模型；匹配内置模型元数据库后自动带出推荐显示名、上下文长度及视觉/工具/推理能力标记，也支持手动输入任意自定义模型 ID。
2. **原子配置写回与内存热替换**：面板新增、编辑或删除提供商与上游模型时，服务将 API 密钥单独写入配置文件同级 `secrets/` 目录下的 `0600` 私密文件（编辑模型留空密钥且端点/协议未变时自动沿用原密钥，显式移除使用 `clear_api_key`），通过临时文件加原子重命名写回 `ocs-tiku-fork.json`，并即时热更新内存中的 `models.Registry`，无需重启进程即可投入作答。
3. **无 Token 预检与确认式功能测试**：发布对外可见的公开条目前自动执行轻量级连通校验；手动发起真实大模型作答的功能测试前，界面强制要求维护员显式确认本次测试将产生上游 token 消耗，并将操作与测试结果记入 `tiku.panel_audit`。

## 2. 外部模型参考价目录与汇率本地缓存

为降低维护员换算每百万/每千 token 人民币微元单价的出错率，面板支持拉取公开大模型定价目录与实时外币汇率，自动换算填入**普通输入、输出、缓存读取、缓存创建**四项参考费率（仅在新建公开条目或切换关联模型时自动填入，编辑已有条目时保留已发布费率）：

- **磁盘缓存与启动预热**：参考价目录与汇率数据缓存在题库配置文件同级的 `cache/` 目录下，`pricing_cache.catalog_ttl_hours` 与 `exchange_ttl_hours` 默认均为 `24 小时`；服务启动时后台异步预热，外部网络不可达时平滑降级为手动输入费率，不阻断面板或查题服务。
- **在线即时刷新**：在面板“设置”页修改参考价或汇率的缓存 TTL 保存后**立即生效**，并提供“立即刷新”按钮（请求上限放宽至 `40s`）；修改监听端口或并发上限（`limits.concurrency`，范围 `1–16`）等底层运行参数在保存后提示重启 `ocs-tiku` 服务生效。

## 3. 面板安全边界与统计聚合

- **会话与跨站隔离**：面板启用 `HttpOnly`、`SameSite=Strict` 会话 Cookie（进程内有界存储，8 小时过期）及严格 CSP 响应头；所有 `/panel/api/*` 请求校验 `Origin == panel.origin` 且拒绝 `Sec-Fetch-Site: cross-site`。本地开发专用的 `panel.local_auto_login` 仅在配置为回环 HTTP Origin 且实际请求来源与 `Host` 均为回环地址时生效，生产配置校验直接拒绝开启。
- **统计同源一致性**：面板“运行总览”中的近 14 天查询与精确缓存命中趋势图、累计按模型调用分布图及底部统计表统一聚合自同一份 `tiku.queries` 持久化查询事实，配合分页索引（题库迁移 06）避免大表全扫。
