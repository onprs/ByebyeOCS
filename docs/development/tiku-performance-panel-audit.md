# 题库性能与维护面板复查

本文面向开发维护环境。本轮使用隔离 PostgreSQL、合成账号和本地 TLS 模型夹具，没有访问真实模型、学习平台、支付渠道或生产主机。公开安装与升级说明见题库 README。

## 模型与维护界面

- 提供商管理协议、地址与密钥，模型引用提供商；同一连接可被多个模型使用。旧模型内嵌连接配置仍可读取、编辑，也可改为引用提供商。不同协议的网络安全边界保持不变。
- 模型、提供商与公开价格分开呈现；同一模型的多个公开条目分别展示。条目可重新关联模型；无论条目是否下架，被引用模型都不能删除。
- 提供商修改先写新的私密密钥文件并校验完整配置，再切换运行时快照；使用需要密钥的协议时，修改地址或协议需要重新提供密钥。失败后原密钥保持不变。模型与密钥、图片转述模型及其密钥从同一快照读取。
- 配置文件与数据库不能组成同一事务：先记录操作意图，再写文件；结果审计写入失败时返回待核对提示。公开条目变更和审计在数据库同一事务提交；切换默认条目会更新原条目的版本。
- 连通性测试在不支持该探测方式的协议上显示明确原因；功能测试需要确认用量。空回答不能标记为功能测试成功。

## 缓存、异常与性能

- 缓存键纳入实际模型连接、密钥摘要、图片转述模型和有效输出预算。模型名称等纯展示字段变化不使缓存失效。升级后旧格式缓存按原期限清理，不再命中；原幂等键和价格快照不变。
- 上游结果或费用不明、已发生的部分调用后续失败、调用明细写入失败均进入 `request_unknown`，禁止同键再次调用；部分已确认 token 在写入成功时保留，整体用量标记不完整。主平台进入待复核，不自动扣费。
- 负数或矛盾的 token 不标记为完整。模型调用记录按真实完整性保存，不以字段存在代替用量校验。
- 模型请求复用同主机空闲连接；域名有多个地址时依次尝试符合网络边界的地址，私有及共享地址仍被拒绝。请求响应和密钥文件继续有大小上限。
- 记录列表分别对幂等请求和兼容查询做有界分页后合并；缓存及审计分页按原生 UUID 排序。总览从按模型聚合推导累计数据，避免对查询事实进行第二次全量累计扫描。
- 5,000 条隔离请求的查询计划检查确认分页索引可用于限量排序；同一时间戳、兼容查询、模型和状态筛选、跨页去重有回归。该结果不代表真实负载或生产容量。

## 数据库与升级

题库新增连续迁移 [000006_panel_pagination.sql](../../services/tiku/internal/platform/store/migrations/000006_panel_pagination.sql)，历史迁移未修改；主库本轮没有新增迁移。服务仍不自动迁移，启动会校验题库迁移版本。

现有部署升级前应备份题库数据库和配置，使用新版本题库程序显式执行 `migrate`，确认成功后再启动服务。此工作区的修改没有部署到生产环境；当前生产迁移状态以维护环境实际检查为准。

## 验证

- PostgreSQL 16.15 与 17.11 的隔离测试均通过 fork 全量竞态回归；Go 静态检查覆盖全部 fork 包。测试覆盖旧配置兼容、共享连接、密钥轮换失败、模型/密钥并发快照、缓存隔离、异常用量、审计写入失败和分页。
- 主平台与真实 fork 进程的跨服务回归覆盖预占结算、缓存、幂等及上游错误待复核；上游为本地 TLS 夹具。
- 真实浏览器覆盖维护员与只读账号、提供商及模型增删、公开条目编辑与关联变更、模型测试、缓存失效、外观切换；提供商页面在 320、390、768、1024、1280、1440 像素检查横向溢出和地址/状态重叠，六个手机页面加载通过。

验证只证明本地受控数据、所列数据库版本与浏览器下的行为。真实供应商的延迟、限流和计费，以及目标机器的容量，仍需对应授权和现场测量。
