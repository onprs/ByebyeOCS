# 课程目录读取审计与修复

范围：Go 主服务、Flutter 正式用户端及主库迁移 27。本文面向开发维护环境，记录源码修复、离线响应回放和隔离数据库验证；公开安装前提沿用项目部署文档。

## 问题与修复

| 问题 | 原因与修复 |
| --- | --- |
| 章标题缺失、小节平铺、编号丢失 | 原目录读取只提取 `toOld(...)` 入口和节点标题，遗漏无任务标识的章分组及嵌套 `li/ul`。新解析器按平台 DOM 前序保存章分组、父标识、原始编号与小节，保持原顺序。 |
| 详情偶发缺章或概要与附件不一致 | 同步会复用章节 UUID 并更新版本，原详情的多条查询可跨越同步提交。详情改用 PostgreSQL 只读可重复读事务。 |
| 同一媒体的不同任务点被合并 | 原快照去重和数据库唯一约束只区分媒体对象。现在同时区分对象与任务点，分别保存卡片页码及个人进度。 |
| 普通资料进度污染任务完成状态 | 普通附件与任务点合并时，只允许补充名称、类型、时长；完成字段、播放位置和卡片位置取任务点自身。 |
| 升级后恢复逻辑复用旧的平铺目录 | 适配器更新为 `chaoxing-read-v2`，中断恢复只跳过当前适配版本已提交的完整课程。 |
| 大目录产生逐条数据库往返 | 稳定章节 UUID 一次读取；章节、附件和任务按依赖顺序批量写入，每批约 256 条语句，整体仍在同一事务中。 |
| 平台进度被当成实际播放记录 | 课程卡片的学习时长单独展示为平台记录时长，实际播放证据缺失时明确显示无播放记录。 |
| 前端分组和展开状态错位 | Flutter 按父标识构建目录树并汇总子树任务点，折叠节点使用稳定章节 UUID 作为 key；刷新重排不交换展开状态。 |

重复标识、缺失父节点、环、超出 32 层、目录分组携带附件，以及同一任务点的对象或完成事实冲突均在写入前拒绝。目录身份继续核对课程、班级和 CPI；HTML 属性中的引号实体由 HTML 解析器解码。未知结构不提交部分目录。

## 数据与交互契约

课程详情仍返回平铺的 `chapters` 数组，数组顺序为平台目录前序。每个节点新增 `parent_external_id`、`number` 和 `is_group`，具体字段见 OpenAPI。根节点父标识为空，父标识在同一课程内关联 `external_id`。

没有平台任务标识的章标题使用 `catalog-group:` 命名空间，根据平台编号与标题确定目录标识；该标识只用于目录关联，不发送给卡片或执行接口。标题或编号改变可以生成新的分组标识，实际小节继续使用平台标识和既有 UUID。

详情页按原始层级折叠，分组统计包含子树任务点，普通资料不计入任务点。安排编辑器显示相同层级，勾选分支会展开为其中实际小节的 UUID，分组自身不进入安排。部分选中的分支显示中间状态。原有安排保留明确选中的章节，保存后的范围不会因新增子章节自动扩大。选定范围沿用服务端 200 章上限。

## 性能边界

课程列表的名称、教师和封面共用一次 HTML 解析，目录的标题、层级和计数共用另一棵目录 DOM。详情的普通资料数量直接使用快照汇总，避免再次扫描附件。迁移补充稳定章节查找和当前版本附件排序索引。选定章节归属校验改为一次成对批量查询。

本机合成目录基准包含 16 个分组、256 个小节，约 61 KiB，解析约 1.68 毫秒/次、分配约 1.33 MiB/次。隔离 PostgreSQL 合成快照包含 150 个章节、150 个任务点，内容写入实测为 2 个批次、450 条语句，完整事务约 35 毫秒。该结果只描述本地受控数据与本次环境，不代表真实平台同步耗时或生产容量。

平台请求继续遵守原有速率限制、最多四个并发章节与会话隔离。个人完成状态仍需读取当前账号的卡片，24 小时共享缓存仅保存卡片页码目录。网络请求数量和上游响应时间仍决定真实大课程的同步耗时。

## 验证结果

- 36 份维护环境已保存的真实目录页面离线回放通过：2,979 个目录节点、309 个分组，最大五层。页面和账号数据不进入仓库；这次回放没有发起平台请求。
- 合成回归覆盖多层目录、平台顺序与非顺序 ID、编号和标题、分组不发起卡片请求、冲突身份、重复/漏项、空目录、独立进度，以及旧平铺响应。
- PostgreSQL 回归覆盖层级保存、同媒体多任务点、稳定章节与既有安排关联、分组拒绝进入安排、旧适配版本恢复、后续批次失败完整回滚和大目录跨批次提交。
- 用受控查询屏障在概要读取后提交新快照，确认详情仍返回旧版本的完整章节和附件。
- Flutter 回归覆盖手机与桌面目录折叠、刷新重排后展开状态、分支勾选与实际保存范围；全量 124 项测试和静态分析通过；手机深层目录验证覆盖 32 层，缩进有界，平台进度与实际播放记录分别展示。
- 主服务 `go vet ./...`、`go test -race ./...`、全量隔离 PostgreSQL 集成测试及 OpenAPI 校验通过；主服务二进制与 Flutter Web release 构建通过。

## 发布前 CI 补充

完整 CI 暴露自定义安装路径的上级目录可能在私有 umask 下被隐式创建为 0700。安装工具改为逐级显式创建缺失的可遍历目录，已有父目录权限保持不变，已有私有配置目录也不临时放宽。部署与备份脚本的 60 项隔离测试通过，并保留已有私有父目录权限的断言。

## 升级要求

迁移 `000027_learning_chapter_structure.sql` 新增目录编号与分组字段，调整附件唯一约束并增加读取索引。升级前需要显式执行新增迁移；本次只在隔离测试数据库执行迁移。

既有平铺快照缺少原始父子信息，不能从标题推断补齐。升级后重新发起一次课程同步，完整读取成功的课程才会显示新层级，失败课程保留旧快照。部署仍沿用既有配置、数据库密码和密钥。迁移仅放宽附件唯一约束并添加字段/索引，不重建学习身份和钱包。
