# 用户客户端界面规范

> **适用范围**：正式 Flutter 用户端（`apps/client_flutter/`）在桌面 Web 与移动视口（Android / iOS / 窄屏浏览器）的界面与交互设计规范。

## 1. 界面心智与信息克制

用户客户端面向终端学习者，界面聚焦于**课程、任务安排、执行进度与账户余额**四个核心概念，屏蔽后台租约、fencing token、上游协议、内部缓存枚举（如 `cache_first`）等工程术语。所有界面文案直接陈述面向用户的可理解状态，移除页面标题下方的固定功能解说与底部常驻说明条。

## 2. 响应式壳层与统一页脚

- **自适应导航**：宽屏桌面端在 `64px` 顶栏内展示品牌标识、居中 `SlidingSelectionBar`（首页、课程、安排、钱包）与右上角个人头像按钮；窄屏移动端隐藏顶栏滑块，启用底部四栏等宽导航并适配系统安全区（Safe Area）。
- **页脚滚动布局**：除钱包页采用 `CustomScrollView` 懒加载 Sliver 列表（空态或短列表时同样保证页脚贴底）外，其余主页面统一封装于 `PageScrollView` 容器中——正文不足一屏时页脚固定贴齐视口底部，正文超出一屏时页脚随内容自然滚动至最末尾，窄屏与大字号下自动折行，显示版权年份与 `Created by onprs`。

## 3. 各核心页面设计规范

### 3.1 登录与连接服务

- **登录页（`/login`）**：单卡片极简结构，仅包含学习通账号与密码输入框及提交按钮；不预设猜测性的图片验证码输入框或学校选择器，学校名称在登录核验通过后由服务端返回。
- **连接服务页（`/connect`）**：专为原生客户端提供，校验 HTTPS 地址格式并探测服务端能力接口；切换服务地址前明确告知将清空本地已有登录态。

### 3.2 首页（`/home`）

- **主视觉与概览**：顶部主视觉卡片左侧呈现欢迎语与学习概况，右侧铺满展示当前重点课程的真实封面（缺图或加载中平滑回退至几何占位图）；并排配对等高的钱包快捷卡与统计指标带。
- **唯一内联同步条**：课程同步状态由全局 `CourseSyncController` 驱动，在首页与课程页共享同一内联进度条；用户手动关闭某次完成提示后，同一同步批次在轮询或切页时不再重复弹出。
- **可处理异常提醒**：通过 `GET /tasks?actionable=true&limit=1` 读取当前未归档安排下真正需要用户介入的异常总数（`total_count`），自动排除已归档安排、历史旧版本与平台已关闭任务。

### 3.3 课程列表与多级目录详情（`/courses`、`/courses/:id`）

- **课程网格**：采用固定高度（`330px`）卡片展示受保护代理封面、课程名、教师、进行中/已结束标签及任务点完成进度；已结束课程灰化标记，不计入待完成统计，且不可被选入新安排。
- **目录详情**：顶部汇总整课进度并提供“加入安排”快捷入口；正文按学习通原始章分组与多级父子层级展示可折叠目录树。每个节点清晰区分带编号的有效任务点与普通学习资料，已关闭小节展示“已关闭”标签并隐藏无效进入动作；平台确认状态变���后实时局部刷新进度，无需整课重同步。

### 3.4 任务安排与执行进度（`/plans`）

- **编辑器容器**：桌面端点击新建或编辑在右侧滑出 `600px` 抽屉，移动端弹出底部圆角面板（Bottom Sheet）。
- **表单设计**：课程选择器支持按课程名或教师实时模糊过滤（过滤词变化不影响已勾选集合），范围统一覆盖所选课程的全部可用章节。启用“测验”后展开题库配置：模型选择器仅显示模型名称与“支持图片题”标记（隐藏微元费率与底层协议），复用方式使用单选卡片展示“优先复用答案”与“每次调用模型”。删除安排采用归档语义，隐藏出列表并停止后续派发，保留既有任务与账务记录。
- **双层进度条与分页**：安排头部展示服务端统计的当前版本全量绑定总进度条（已完成、待执行、需要处理、已取消，数值不受列表分页影响）。下方任务列表按分类（当前、需要处理、已关闭、已完成）配合服务端一致快照游标分页（每页 10 条）；每行移除冗余文字状态胶囊，改用独立进度条直观表达确定比例、执行中不确定扫光、平台已确认或异常暂停状态。点击任务行打开详情面板，分别查阅执行观察、平台确认依据与媒体记录，并提供暂停、继续、取消及“重新调度”（已关闭任务显示为“重新检查可用性”）。

### 3.5 钱包、个人设置与独立题库查询

- **钱包页（`/wallet`）**：顶部大字号展示可用余额（全角 `￥`）与预占金额，下方通过滑动页签切换充值订单、账本流水与题库 token 用量；订单行明确区分“已支付待入账”与“已入账”。
- **个人设置（`/settings`）**：采用单表面分组列表，外观区域使用直观的石墨/青禾/靛蓝配色预览卡片与跟随系统/浅色/深色主题卡片（不使用下拉选择框），下方依次排列独立题库查询入口、通知偏好、活跃会话吊销、个人数据导出及账号删除申请。
- **独立题库查询（`/settings/questions`）**：支持选择题库面板已发布的模型与复用方式查询单题答案，展示缓存命中或 token 分项消耗；对存疑结果可在当前页内平滑展开问题报告表单直接提交。
