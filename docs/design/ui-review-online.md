# 跨端视觉与版式收敛准则

> **适用范围**：开发维护环境。本文总结 Flutter 用户端、React 管理员控制台与独立题库维护面板在多轮真实视口（桌面 `1440px` 与手机 `390px`）走查后固化的版式与信息收敛规范，作为后续新增页面或组件的审查清单。

## 1. 信息减法与防堆叠准则

1. **禁止“卡中卡”嵌套**：同一功能分区仅使用一层主表面卡片（`surface` + `1px border`），内部子项采用细分隔线（`border`）或浅底条（`surface-subtle`）组织，消除多层圆角边框与多重阴影叠加造成的视觉拥挤。
2. **禁止指标卡片泛滥**：多维统计数字统一收拢至单条水平指标带或分组摘要行中，避免把每个单独计数器做成等大彩色方块占满首屏。
3. **清零冗余解释文案**：页面主标题下方不放置常驻的功能介绍副标题；页面底部不放置面向用户的系统规则长说明条；表单标签已清晰表达含义时不重复添加占位符式帮助小字。
4. **严格面向用户措辞**：任何界面均不得出现内部字段名（如 `cache_first`、`always_llm`、`usage_incomplete`）、接口路由、数据库状态枚举或面向开发者的调试说明。

## 2. 跨端几何与对齐规范

1. **三端同源几何**：石墨、青禾、靛蓝三套外观仅切换色彩令牌，严格共享相同的圆角（`6/10/14px`）、控件高度（`36px` 桌面 / `44px` 触控）、字级标尺与容器内边距。
2. **并排卡片等高与封面铺满**：首页主视觉区右侧封面完整铺满容器并与左侧文字区严格分区保障可读性；双列或多列并排卡片（如总览双图表卡、首页概况与钱包卡、课程网格卡 `330px`）保持同行等高对齐。
3. **全宽随滚页脚**：三端页脚统一位于页面流最末端并横向铺满内容区边界——短页面贴合视口底边，长页面随滚动到达底部后自然呈现，不遮挡正文或底部浮动保存栏。
4. **表格内局部滚动**：宽数据表设置明确列宽与截断省略，超出视口宽度时仅在表格外层容器内部产生横向滚动，保证 `390px` 手机窄屏下整页零横向溢出。

## 3. 组件交互一致性清单

新增或修改界面提交代码前，按以下标准逐项核验：

- [ ] 切换石墨、青禾、靛蓝与浅深模式后，全部文本与状态徽标对比度均不低于 `4.5:1`，不存在残留硬编码亮色背景或黑字。
- [ ] `1440×900` 桌面视口与 `390×844` 移动视口下均无整页横向滚动、文字截断重叠或安全区遮挡。
- [ ] 页签栏、顶栏滑块与设置分组切换时具备连续平滑的选中指示器；开启系统“减少动态效果”后动画自动关闭。
- [ ] 所有金额显示统一使用内置字体支持的货币符号（`￥`）与两位小数格式化，缺失数据统一显示为 `—`。
- [ ] 首屏骨架、按钮内联 loading、抽屉焦点恢复与返回页面滚动位置记忆均正常工作。
