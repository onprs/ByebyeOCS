# 设计系统

整体 UI 已获用户确认。默认使用石墨，青禾与靛蓝保留为用户可切换的外观方案；三者均支持浅色和深色。用户和管理员可以从各自设置中选择，原型分别保存本机偏好。

## 方向比较

| 方向 | 基底与强调 | 结构与排版 | 适合的体验 |
| --- | --- | --- | --- |
| 石墨 `graphite` | 灰白工作区、炭黑侧栏、低饱和蓝 | 较小圆角、紧凑表格、无衬线标题 | 长时间操作、高信息密度和运行监控 |
| 青禾 `grove` | 暖白、森林绿、浅色导航 | 编辑式标题、更舒展留白、自然色插画 | 轻量学习、亲和的消费级产品 |
| 靛蓝 `indigo` | 墨蓝侧栏、靛蓝、深色主视觉 | 几何构图、品牌区块与更明确的对比 | 品牌辨识与行动入口 |

不是只替换主题色：侧栏明暗、密度、标题字体、主视觉结构、插画颜色、导航选中态和圆角均有区别。原型共用功能组件，保持比较时业务条件一致。

## 基础规则

- 颜色语义：强调用于当前操作；绿表示已确认或健康；琥珀表示核验、提醒或需处理；红表示失败与限制。状态同时使用中文文字或图标，不单独依赖颜色。
- 层级：页面标题 → 区域标题 → 当前业务内容 → 辅助说明。管理端比用户端更紧凑，但不使用装饰性的彩色 KPI 网格。
- 排版：优先系统可用字体，数字使用等宽数字特性；青禾标题可使用本地衬线字体。原型不依赖远程字体服务，其他系统的字体外观可能略有差异。
- 用户端正文与关键信息优先保持可读；小字用于辅助索引。已根据 390px 实际截图进行一轮字号和布局校准。
- 图像：本地 SVG 课程插画与结构图形，无外部图片请求；没有课程原封面时不假装使用平台真实封面。
- 动效：仅保留必要的状态反馈、加载与轻微悬停；支持减少动态效果的系统偏好。

## 组件

基础按钮、图标按钮、搜索、下拉选择、多选框、开关、标签、标签页、进度、详情抽屉、对话框、通知与空状态位于 `prototypes/src/ui.tsx`。对话框使用 Radix Dialog，提供焦点管理、Esc 关闭和可访问标题。

题库相关组件包括公开模型选择、作答方式卡片、token 用量块、缓存状态、管理员模型表与缓存策略卡。模型条目同时显示能力与价格状态；缓存命中用绿色和“0 token”表达，不使用模糊进度暗示答案正确。

当前组件为原型自建的 Tailwind/CSS 与 Radix 组合，没有宣称已生成完整 shadcn/ui 组件库。UI 方向已确认；正式组件规范和工程组织按技术验证与开发路线收敛。

## 尺寸和适配

- 管理端：宽屏固定导航与可滚动表格；中屏缩为图标导航；窄屏保留表格内部横向滚动，不让整页溢出。
- 用户桌面：约 1,176px 内容工作区，课程三列，任务安排列表与详情并列。
- 用户窄屏：700px 内容容器断点下切换为底部导航、两列课程卡、折叠安排选择器、配置摘要与底部编辑。
- 手机主导航、主要确认按钮及编辑控件扩大触控范围，并保留安全区。密集任务行的次级图标仍应在后续原生实现中继续优化触控面积。
- 浅深主题覆盖背景、表格、状态、图表、主视觉、输入和弹层；不只反转页面背景。

## 样式组织

| 文件 | 职责 |
| --- | --- |
| `styles.css` | 设计变量、共享组件、评审入口与管理端 |
| `client.css` | 用户端页面与登录流程 |
| `variants.css` | 三方向差异、容器断点和手机布局 |
| `readability.css` | 第一轮实机截图后的字号、触控与安排摘要校准 |
| `appearance.css` | 已确认的三色选择组件，管理端与用户端共用 |
| `question.css` | 模型选择、缓存方式、token 用量与管理员模型目录 |

这些文件服务于交互原型。正式实现使用统一变量生成 CSS/Dart，并收敛组件变体，避免长期维护原型覆盖层。外观决策见 `docs/decisions/0002-default-graphite.md`。
