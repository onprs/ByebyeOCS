# 管理员控制台设计

管理员的任务是判断运行是否健康、快速定位异常、批量处理和复核资金。布局围绕这些动作组织。

## 运行总览

首屏分为系统状态带、四项关键指标、任务趋势与运行资源。下方提供处理中的任务、今日财务和实时事件，均可跳转到具体工作页。

不把所有指标做成彩色卡片：总用户和活跃会话用同一指标带；CPU、内存、Goroutine、API P95、Worker 名额和题库状态放在运行资源中；充值和待入账放进财务区域。

图表和运行值是合成数据，不对应真实容量测试。趋势中的执行观察与平台确认分开呈现。

## 用户与账号

概览可直接筛选会话状态，工具条支持搜索、状态、排序与重置。表格提供当前页多选，换页或改变搜索时清除选择，避免默默扩大操作范围。

选中后出现批量操作条：暂停任务、调整账号并发、限制账号。操作面板显示范围并要求原因。限制可在详情中解除，但解除后仍需重新验证会话。

详情抽屉展示学校、内部用户编号、脱敏外部主体摘要、会话、课程与余额；任务入口带上用户筛选。凭据仅展示加密状态。

## 全局任务监控

并发摘要区表达全局名额、账号默认上限和同任务独占。状态标签区分全部、执行与验证、队列、异常和历史。

每行展示任务编号、课程、用户、执行阶段、观察进度、平台结果与最近更新。平台确认列独立于观察进度，100% 也可以仍在等待验证。

详情分别展示处理观察、平台依据和媒体记录，配合时间线与暂停、继续、取消和重新调度。批量操作跳过状态不适用的任务；平台已确认任务不回退重试。

## 题库查询与用量

独立页面，顶部汇总累计查询、精确缓存命中率、输入/输出 token 和成本状态；未定价时显示“价格待公布”，不显示虚假收入。页面主操作是“进入题库面板”，侧边导航也提供同域 `/panel/` 入口。

公开模型表为只读目录：公开名称、公开编号、文本/图片能力、输入/输出价格、缓存策略、默认项和发布状态。新增、编辑、下架、排序、设为默认、价格版本与模型测试都在题库维护面板完成；主管理端不提供这些写操作。

目录不硬编码：价格版本由题库面板发布，主平台读取后同步镜像，并在查询时冻结。未配置价格时用户显示“价格待公布”，不启用真实扣费。

缓存行为只做说明和核对：精确匹配、用户隔离为默认、TTL 与共享开关按条目发布；错误缓存可通过查询详情发起失效。共享缓存默认关闭，开启前需要隐私评估与失效方案；模糊历史候选不显示为缓存命中。

查询与用量区按状态、模型和当前页搜索筛选，展示缓存命中、token 分解、`usage_incomplete` 和待核对；答案报告在本页复核，金额与计费状态保持可解释。

上游密钥、真实模型 URL 和服务商凭据留在独立 fork，不在任一管理页面回显。

## 财务与订单

订单、余额流水与人工审计独立切换。支付成功但未入账、异常、关闭、退款都有不同状态。

人工调整要求：内部用户、整数分对应的金额、非空原因、权限确认。原型演示非负余额校验、单条流水和审计；真实权限与数据库事务尚未实现。

对账中心展示异常复核与备注保存，不伪装为已连接真实支付平台或已完成退款。

## 系统设置

12 类设置包含基础、平台、会话、调度、题库、计费、支付、权限、通知、数据备份、安全与运行更新。基础设置新增当前管理员的三种配色与浅深模式，默认石墨；与普通用户偏好独立保存。

题库连接、服务间认证、并发和超时由部署配置提供；系统设置只显示题库计价入口并跳转题库维护面板，模型、价格和缓存策略不在设置长表单里重复。

计费设置显示主服务按“平台已确认的有效任务点”计量、题库按 token 独立收费；题库 token 价格版本在题库面板发布，主管理端只保留扣费开关与核对，真实扣费保持关闭。ZPay 已确定 zpayz.cn，真实商户尚未配置。

设置采用独立侧导航和连续表单。连接可达性与会产生模型成本的功能性测试分开；凭据脱敏展示。调度策略保存后，监控页显示对应的全局与账号上限。

审计、密钥加密和用户隔离是正式服务的硬性边界；原型中的“始终开启”表达产品约束，不表示已经有可部署的安全实现。
