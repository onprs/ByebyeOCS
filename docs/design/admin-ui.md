# 管理员端与题库面板界面规范

> **适用范围**：正式 React 管理员控制台（`apps/admin/`）与独立题库维护面板（`services/tiku/internal/platform/panel/`）的界面结构与交互设计规范。

## 1. 管理员控制台整体布局

管理员控制台服务于高信息密度的日常巡检、批量管控与资金复核。桌面端采用左侧 `224px` 深色常驻侧栏加右侧自适应内容区；常规管理页面最大宽度 `1280px`，包含多列数据表的任务监控与财务页放宽至 `1440px`。宽表仅在自身表格容器内横向滚动并显示边缘阴影提示，严禁产生整页横向滚动条；页面切换后自动记忆并恢复滚动位置，关闭抽屉或对话框后将键盘焦点归还触发按钮。

## 2. 管理端核心页面设计

### 2.1 运行总览（`/dashboard`）

- **状态横幅与关键指标带**：首屏顶部集中呈现服务就绪状态、异机备份新鲜度、恢复门控（`.recovery-required`）与磁盘水位预警；下方使用紧凑同surface指标带展示用户与活跃会话、活跃租约、队列积压、已关闭任务数（`closed`）及真正需介入的可处理异常数（`actionable_attention`，平台正常关闭项不混入异常告警）。
- **资源与动态**：分栏呈现进程内存/协程/连接水位、进行中任务快照、今日充值与待对账摘要及实时管理员 SSE 事件流，各模块均支持带筛选条件一键跳转对应工作台。

### 2.2 用户与账号（`/users`）

- 支持关键字搜索、平台会话状态筛选与排序；表格复选框仅作用于**当前页**可见行，翻页或更改筛选条件时自动清空已选集合，防止误操作不可见记录。
- 勾选后浮现批量操作栏（暂停该批用户任务、调整单账号并发上限、限制账号登录与执行），所有批量与单人管控动作均要求填写非空审计原因。
- 用户详情抽屉展示内部 UUID、学校、脱敏外部主体指纹、加密凭据状态、活跃会话、已同步课程数及钱包余额，绝不展示明文密码或平台 Cookie。

### 2.3 任务监控与答案报告复核（`/tasks`）

- **并发与队列视图**：顶部展示全局并发名额与单账号并发上限，按分类页签筛选全部、执行与核验中、排队中、需要处理、已关闭与历史终态任务。
- **双列独立呈现**：表格同时列出“执行观察进度”与“平台核验状态”两列，直观体现“观察进度 100% 仍需等待平台核验通过”的业务边界；详情抽屉完整呈现执行尝试时间线、错误码、平台核验时间戳与媒体播放证据标记。
- **答案问题报告面板**：当系统内存在待处理的用户题库答案报告时，任务监控页底部展示 `QuestionReportsPanel` 复核专区，支持管理员审阅报告说明、填写处理意见结单，或一键联动题库服务使对应精确缓存失效。

### 2.4 财务与订单（`/finance`）、管理员（`/administrators`）与隐私（`/privacy-requests`）

- **财务工作台**：分设充值订单、不可变复式账本流水、渠道对账与退款审批视图。执行人工余额调整或原路/服务退款时，强制弹出 `StepUpDialog` 要求管理员完成近期密码/TOTP 步进验证并填写非空原因，金额统一按精确元角分输入并转换为整数分提交。
- **管理员与角色**：清晰列出五类角色（`owner`、`operator`、`support`、`finance`、`observer`）及其权限边界；界面与服务端双重拦截停用或降级最后一个有效 `owner`。
- **隐私请求**：集中展示个人数据导出记录与账号删除申请，清晰提示未决订单或在途预占阻塞项，辅助客服或合规人员完成闭户审批。

### 2.5 系统设置（`/settings`）

采用左侧 `SelectionTrack` 分组导航加右侧单表面卡片表单，收敛为四个清晰分区：

1. **外观偏好（`appearance`）**：独立保存当前管理员的石墨/青禾/靛蓝配色与跟随系统/浅色/深色主题。
2. **计费与价格（`billing`）**：配置有效任务点微元单价、整数舍入方式（`ceil` / `floor` / `half_up`），管理主服务扣费与题库扣费总开关。
3. **运行安全（`runtime`）**：查看各项外部能力启用状态；`owner` 可直接在线调整全局执行并发、单账号并发、单课章节同步并发、上游请求最小间隔及自适应提速下限，底部固定保存栏即时生效并持久化。
4. **维护信息（`maintenance`）**：只读核对构建版本、数据库迁移版本、磁盘空间与最近一次异机加密备份校验状态。

## 3. 独立题库维护面板（`/panel/`）

题库维护面板复用同一套 `tokens.css` 视觉变量、配色卡片与页脚规范，窄屏下自动切换为等宽网格导航：

- **运行总览**：上方并排等高卡片呈现最近 14 天查询量与精确缓存命中率柱线趋势图、累计按模型调用占比图，下方展示全局 token 汇总与最近查询列表（空状态采用简洁文本呈现）。
- **模型与价格**：拆分为“上游提供商”“上游模型”与“公开模型与价格”三层协同区域。添加提供商支持一键测试连通并拉取上游模型目录，自动匹配填充上下文窗口、视觉与推理能力；每个上游模型最多绑定一个公开条目，新建公开条目或切换关联模型时自动拉取外部参考价并按实时汇率换算填入普通输入、输出、缓存读取与缓存创建微元参考费率（编辑已有条目时保留原费率防误覆写），支持独立下架或删除公开条目。
- **查询记录、精确缓存与操作记录**：采用行式摘要配合右侧详情分栏，支持按条件检索调用槽位明细、带原因失效单条精确缓存及查阅 180 天内的面板审计日志。
- **面板设置**：提供配色与主题预览卡片、服务运行参数修改（标注需重启生效项），以及模型参考价目录与汇率本地缓存 TTL 调整和立即刷新按钮（加载动画与状态同排就地反馈）。
